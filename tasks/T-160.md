# T-160 — Claude `inherit` używa domyślnego modelu zamiast nazwy literalnej

Importowany agent Claude'a może mieć `model: inherit`. W definicji subagenta Claude Code ten
tekst znaczy „użyj modelu sesji nadrzędnej”; nie jest nazwą modelu do przekazania głównemu CLI.
Loadout zachowuje tę wartość w bibliotece, a sterownik wysyła dziś `--model inherit`, więc Claude
2.1.247 odmawia przed pierwszym tokenem jako `unrecognized_model`.

Naprawa należy do adaptera Claude'a, nie do ogólnego `RunSpec` ani importera. Dzięki temu działa
również dla agentów już zapisanych w `~/.loadout`, bez migracji plików i bez zmiany wartości
widocznej w definicji źródłowej. Każdy inny niepusty model nadal jedzie do CLI co do bajtu.
