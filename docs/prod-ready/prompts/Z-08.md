# Z-8 — Skille i artefakty poza commitem kroku

skills/place.rs into_the_step_folder kładzie cały katalog umiejętności w cwd/.agents/skills/ dla obu vendorów, a isolate::save robi git add -A, więc skille Loadouta lądują w commicie kroku i w gałęzi wynikowej człowieka. Napraw dwie rzeczy: (1) półkę .agents/ kładź tylko dla sterownika, który nie umie przyjąć skilli argumentem (inheriting() == None), a w każdym worktree kroku dopisz .agents/ do pliku info/exclude tego worktree (git rev-parse --git-path info/exclude), nigdy do .gitignore człowieka; (2) w isolate::save przed add -A policz rozmiar nieśledzonych plików i powyżej progu (np. 50 MB) zapisz je jako left_behind z jednym zdaniem zamiast commitować. Testy: krok z umiejętnością na fresh-copy — commit kroku bez .agents/ (na starym kodzie zawiera); krok, który zostawia 100 MB w dist/ — commit bez dist/, zdanie w run.json.
