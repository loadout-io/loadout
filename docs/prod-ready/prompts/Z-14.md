# Z-14 — Transkrypt zachowuje wyniki narzędzi; igły z sufitem

Rozpoznawaj echo wejścia po treści koperty (blok text równy zapamiętanej turze), nie po type. Igły prywatności: dolna granica długości (≥ 32 znaki), dla obrazów porównuj hasz bloku source.data zamiast skanować base64, sufit liczby igieł (ostatnie 16 tur), deduplikacja, jedno parsowanie JSON na linię (przekaż Value z decode do filtra). Testy: dopisz linię user/tool_result do fikstury stream_raw_tee_live i asertuj bajtową identyczność (na starym kodzie linia znika); tura ok po której przychodzi result z input_tokens — result jest w tee; test rozmiaru igieł po 100 turach.
