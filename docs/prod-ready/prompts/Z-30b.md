# Z-30b — Wycieki silnika, drugie podejście: dowód śmierci ma nadal nieść kod wyjścia

Pierwsze podejście (`z30-engine-small-leaks`) dostało werdykt DZIALA, **wlało się i zostało
cofnięte** (`4778c4af`), bo pełne CI po merge'u złapało prawdziwą regresję. Praca jest na gałęzi
`h-z30-engine-small-leaks` i **jest materiałem źródłowym**: wszystko poza jedną rzeczą przechodzi
bez zmian. Nie pisz jej od nowa.

## Co dokładnie się zepsuło

`Supervised::wait()` zaczął ustawiać `self.proved_dead = true`, kiedy po zebraniu lidera żadna
znana grupa nie odpowiada na sygnał zerowy. Sam pomysł jest dobry — dowód z niezmiennika 6 jest
w tym miejscu darmowy. Ale `stop()` zaczyna się od:

```rust
if self.proved_dead {
    return GroupProof::Dead { status: None };
}
```

…więc uchwyt, którego status zebrał już `wait()`, oddaje przy anulowaniu `Dead { status: None }`.
Wywraca to istniejące kryterium, którego zawężony `rust-test` nie uruchomił ani razu:

`src-tauri/tests/it/claude_cancel_escalation.rs`,
`under_the_capability_the_session_is_asked_to_stop_and_ends_itself` — pada na
`status.ok_or("the leader's exit status was never collected")?`.

Ten test nie jest formalnością. Pilnuje różnicy, na której stoi produkt: proces poproszony
grzecznie **wychodzi sam**, więc status nie ma sygnału, transkrypt się dopisuje, haki `SessionEnd`
biegną, a sesja zostaje wznawialna. `status: None` kasuje jedyny dowód, że tak właśnie było.

## Co zrobić

Ten sam kształt, ale bez gubienia statusu. Kandydat, który godzi oba kryteria naraz:

```rust
if self.proved_dead {
    return GroupProof::Dead { status: self.status.take() };
}
```

`take()` oddaje kod wyjścia **dokładnie raz**, więc drugie zatrzymanie nadal odpowiada
`Dead { status: None }` — czego wymaga `stopping_a_group_twice_still_answers_dead_without_a_status`
i co opisuje komentarz przy `stop()`. Sprawdź to sam i wybierz najlepszą drogę; ta jest podpowiedzią,
nie poleceniem.

## Kryterium

1. `claude_cancel_escalation::under_the_capability_the_session_is_asked_to_stop_and_ends_itself`
   zielone, bez ani jednej zmiany w tym pliku. Jeśli uważasz, że test jest zły — **zgłoś to i stój**
   (AGENTS.md §7), nie zmieniaj wyroczni.
2. `stopping_a_group_twice_still_answers_dead_without_a_status` nadal zielone.
3. Wszystkie kryteria pierwszego podejścia zostają spełnione (`z30_engine_small_leaks`
   z gałęzi wchodzi w całości).
4. **Uruchom PEŁNĄ suitę integracyjną, nie zawężoną:** `cargo test --test it -- --test-threads=1`.
   To właśnie zawężenie przepuściło regresję za pierwszym razem. Wynik podaj w podsumowaniu razem
   z liczbą `passed`/`failed`.
5. Komentarz z datą 2026-09 przy samym miejscu: dlaczego status wolno oddać raz i czemu drugie
   zatrzymanie nadal go nie ma.
