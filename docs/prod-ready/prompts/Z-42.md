# Z-42 — Sonda dostępu do folderu, zanim bieg ruszy

Workspace na Pulpicie (`~/Desktop/Studia/inne-i-zadania`): 42 wpisy „handoffs … could not be
read … Operation not permitted (os error 1)" w `commands/handoffs.rs::handoffs_of_run`. Bieg
startuje, kroki piszą, a sekcja przekazań i historia są puste — z ekranu wygląda to jak
workflow, który niczego nie oddał. Przyczyną jest brak zgody TCC macOS na Desktop dla
`Loadout.app`, nie kod, i nikt tego człowiekowi nie mówi.

Zrób: (1) przy pierwszym dotknięciu folderu (`project_for`, żywy szew — nie martwy kod) sonda:
utwórz i przeczytaj `<folder>/.loadout/.probe`; `EPERM` → Start odmawia jednym zdaniem
w strumieniu: „Loadout can't read this folder. Allow it under System Settings › Privacy &
Security › Files and Folders"; (2) `NSDesktopFolderUsageDescription`,
`NSDocumentsFolderUsageDescription`, `NSDownloadsFolderUsageDescription` w konfiguracji bundla,
żeby system w ogóle zapytał; (3) historia biegu, którego przekazań nie da się przeczytać, mówi to
zdaniem zamiast pustej listy. Drogi: brak zgody przy starcie, zgoda cofnięta w trakcie, folder
usunięty, folder na woluminie tylko do odczytu.

Test w `tests/it`: katalog z prawami `0000` (z `chmod` w teście, przywróconym w `Drop`) → Start
odmawia zdaniem; `read_run_inner` biegu z nieczytelnym `handoffs/` niesie zdanie.

**1. Test musi się SKOMPILOWAĆ na starym kodzie i paść dopiero w wykonaniu.** To jest AGENTS.md
§2a punkt 4, i to na nim padło Z-04: moduł testowy importował nowe typy i wołał nową metodę,

sygnatury z `todo!()`** (albo minimalne szkielety), potem test, który na nich pada w czasie
wykonania, dopiero potem właściwa implementacja. Jeśli nowy test wymaga nowego API, a inny test
regresyjny nie — rozdziel je, żeby ten drugi dało się uruchomić na starym drzewie.

Droga, której nie ruszysz, jest tą, o którą zapyta.
