# Loadout 0.4.0 — context that stays with the work

## Reusable context

Create a named set in **Context**, paste your material or add pictures, Markdown, plain text
and PDFs, then press **Build context**. Saving the draft and preparing PDF pages happen as
part of that action. The result appears on the same screen.

Purpose, preparation instructions, exact rules and the agent/model choice are under **Options**.
Progress explains what is happening; detailed processing information stays under **Details**.
**Stop** is available while preparing documents or building the context.

Attach prepared sets to individual workflow steps, share a selection across a workflow, or
use them in a Lead conversation. Runs keep the versions they started with. Editing a set
does not silently change the material an existing run or replay receives.

## One plan across steps

Steps can create, update or use a shared, versioned work plan. Implementation and QA receive
the same recorded acceptance contract, with required content kept in the prompt and supporting
material available by reference. Plan updates are published by Loadout and recorded with the
run, including repeated steps and replay.

## Fixes and clearer controls

- Long Lead conversations keep receiving replies instead of blocking behind an unread queue.
- Closing a Lead conversation finishes its event reader and records the final result.
- Isolated application data no longer changes the home directory used to find CLI sign-in.
- Context building accepts valid JSON wrapped in a Markdown code block while still rejecting
  malformed answers.
- Agent forms use the available width, keep instructions compact and reveal generation
  controls when requested.
- Context building keeps its active progress and **Stop** button when an early status read
  still returns an older operation.

## Before updating

Updates are manual. Download the DMG, verify its checksum, then drag **Loadout.app** to
Applications. Keep your existing library and project folders. The macOS package targets
Apple Silicon and requires macOS 13 or later.

## Known limitations

- Building Context with Codex CLI 0.153.4 can fail during protected startup. Use **Claude Code**
  to build context while that compatibility issue remains unresolved. This does not describe
  ordinary Codex workflow steps.
- A reply accepted at the exact moment a run ends can be absent from the current screen until
  history is loaded again. The reply remains in the run record.
- Paid tests against live vendor CLIs are separate from the standard CI suite. A green CI run
  alone is not evidence that every locally installed vendor version has passed a live check.

## Verify the download

```bash
shasum -a 256 ~/Downloads/Loadout_0.4.0_aarch64.dmg
spctl --assess --type open --context context:primary-signature -v ~/Downloads/Loadout_0.4.0_aarch64.dmg
```

The release entry includes the exact source commit, CI result and SHA-256 of the published DMG.
Both the application and its disk image must carry their notarisation tickets before publishing.
