# Loadout 0.6.3 — importing a project twice

Importing the same project a second time refused everything: the first file that already
existed in your library ended the whole save, and nothing on screen marked the rows you had
already brought over. You were left to find them by eye among several dozen.

**The scan says what you already have.** An item whose file already sits in this project's
library comes back marked and unticked, and its row says so in the Status column instead of
just quietly losing its tick. A second import now brings over everything the library does not
have yet.

**And if you tick one anyway,** the refusal says how many items clash and what to do about it,
rather than naming one file out of fifty.

**A row held back by a connection says which one.** An agent can declare a tool server inside
its own header, and such an agent is held until that server is turned on. The row now names the
server and the move to make. This is why agents like a design reviewer or a Figma extractor
could sit unticked without explanation.

To update, download the macOS Apple Silicon DMG and replace your existing application.
