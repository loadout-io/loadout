# Loadout 0.6.1 — the import can be finished

0.6.0 gave agents the connections a project has. This release fixes the screen that brings
them in, which could stop with no way forward.

**A way out of the reading gate.** A skill that asks for tools of its own waits until you have
read it — that gate stays, because a skill becomes instructions your agents follow. What was
missing is the other half of what the screen already promised. **Take the unread skills out of
the import** does it for all of them at once, and the footer then says what it left behind:
"Ready to import. 15 item(s) will not be imported, including 13 skill(s) you have not read."
There is deliberately no button that marks them all read without opening them.

**The window says where it writes.** Import reads the folder in the Project folder box, but
writes into the library of the project open in the window — and those can be two different
places. Before you press Import you now read, for example, "Reading /work/urc-monorepo. These
files go into inne-i-zadania (/Users/me/Desktop/inne-i-zadania)." The line after a successful
import names the project too, so files never land somewhere you cannot see.

**And what to do with a conversation already open.** An agent that is already talking keeps the
connections it started with. The import now says so and tells you to start a new conversation
to use what it added.

To update, download the macOS Apple Silicon DMG and replace your existing application.
