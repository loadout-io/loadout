# Loadout 0.5.1 — check models before starting

Agent settings and workflow steps now show models reported by your installed Codex
or Claude Code, including the provider's recommended choice. Use **Refresh models**
to update the list. Your selection is never replaced automatically.

Before starting a workflow, Loadout checks every agent step's model and the reasoning
levels reported by the provider. An unsupported choice stops the workflow before any
agent step starts and identifies the step that needs attention. This also catches
invalid models in later steps, before earlier agents spend time doing their work.

If Loadout cannot check the model list, it explains the problem instead of starting
with an unchecked configuration. These checks do not guarantee that network access
or account quota will remain available throughout a run.

To update, download the macOS Apple Silicon DMG and replace your existing application.
