# Loadout 0.5.0 — osobna konfiguracja każdego projektu

Nowy projekt zaczyna z pustą biblioteką. Agenci, workflowy, Knowledge, umiejętności,
Context i połączenia należą do projektu, także przy starcie biegu i w rozmowie z liderem.
Przełączenie projektu nie przenosi wyników opóźnionych odczytów ani niezapisanych formularzy.

W menu projektu pojawia się **Import setup from project**: wybór projektu, kategorii
oraz pojedynczych kart z podglądem. Workflow pokazuje wymagane zależności. Import tworzy
niezależne kopie, nie nadpisuje istniejących plików i nie kopiuje sekretów ani historii.
Wspólna biblioteka z poprzedniej wersji pozostaje na dysku i jest dostępnym źródłem
jawnego importu. Po aktualizacji zaimportuj z niej potrzebne elementy do wybranego projektu.

Nowa rozmowa zaczyna bez czerwonego wyniku poprzedniego biegu. Historia nadal zawiera
poprzednie wyniki, a trwający bieg zachowuje przycisk Stop. Powtórzenia tego samego kroku
mają jedną kartę, licznik uruchomień i rozwijane stany kolejnych wykonań.

Aktualizacja: pobierz DMG dla macOS Apple Silicon i zastąp poprzednią aplikację.
