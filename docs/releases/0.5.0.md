# Loadout 0.5.0 — separate setup for every project

New projects start with an empty library. Agents, workflows, Knowledge, skills,
Context, and connections belong to their project, including during runs and conversations
with the lead. Switching projects keeps pending responses and unsaved forms in their
original project.

The project menu now includes **Import setup from project**. Choose a source project,
filter by category, and select individual cards with previews. Workflows show their required
dependencies. Import creates independent copies without overwriting existing files or
copying secrets or history. Your previous shared library remains on disk and is available
as an import source. After updating, use **Import setup from project → Previous shared library**
to bring the items you need into each project.

New conversations start without showing a previous run’s failed result. Past results remain
available in History, and active runs keep their Stop button. Repeated executions of the
same step share one card with a run count and expandable execution statuses.

Combining agent results skips files ignored by the project, such as build caches.
When a real conflict occurs, the message identifies the branches where the work is preserved.
Diagnostics distinguish skipped steps from steps that actually completed successfully.

To update, download the DMG for macOS Apple Silicon and replace your existing application.
